# Munibase Development - Public Issue Tracking

**Munibase** is a Second Life Roleplay Community Management system designed to streamline community operations, citizen management, and in-world integrations for roleplay communities.

## Purpose of This Repository

This is the **public-facing issue tracking repository** for Munibase. It serves as the central location for:

- Bug reports from the community
- Feature requests and enhancement suggestions
- General feedback and discussions about the project

**Note:** Active development occurs in a private repository. This repository is dedicated to community interaction and project management.

## Current Status

Munibase is currently in **v1.1 milestone** with the following capabilities:

- **Currency System**: Full economic management with transactions, grants, and balance tracking
- **Status System**: Character status management with visual indicators
- **Titler Display**: Enhanced in-world display with global state modes (OOC, AFK, Admin, Moderator)
- **Color Configuration**: Community-customizable titler colors with live preview
- **Capability Management**: Role-based permissions for global state modes

## Reporting Issues

We welcome community feedback! Please use the issue templates to report bugs or request features:

### Bug Reports

If you've encountered a problem with Munibase, please [create a bug report](https://github.com/nacklequack/munibase-development/issues/new?template=bug_report.md) with details about:

- What you were doing when the issue occurred
- Steps to reproduce the problem
- Expected vs. actual behavior
- Your environment (SL viewer, region, etc.)

### Feature Requests

Have an idea for improving Munibase? [Submit a feature request](https://github.com/nacklequack/munibase-development/issues/new?template=feature_request.md) describing:

- The feature you'd like to see
- The problem it solves or use case it addresses
- How you envision it working

## Contributing

While we greatly appreciate community input through issues and discussions, please note that code contributions are managed through the private development repository. Feature requests and bug reports submitted here will be reviewed and prioritized for implementation.

## Project Scope

Munibase focuses on:

- **Citizen Management**: Registration, profiles, and character lifecycle
- **Economic Systems**: Currency, transactions, and financial tracking
- **In-World Integration**: HUDs, titlers, and other Second Life objects
- **Community Administration**: Role management, capabilities, and permissions
- **Status & Presence**: Activity tracking and visual status indicators

## Getting Help

For questions about Munibase or help with specific issues:

1. Check existing issues to see if your question has been answered
2. Create a new issue with the appropriate template
3. Provide as much context as possible to help us assist you
