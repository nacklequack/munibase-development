# Munibase development history

This repository preserves earlier Munibase issues and roadmap discussions as readable history. Current work is managed privately so reports, resident information, and operational details stay with the people responsible for them. Existing issues remain available for reference; this repository does not accept new work.

## Report a problem

If your community has enabled Discord intake, use `/report-bug` in its Discord server. Review the private preview and confirm the report. Keep the reference in the private receipt so community staff can find your report and follow up. You do not need a GitHub account.

If `/report-bug` is unavailable, contact your community staff privately. Do not post account details, resident information, or incident details in this repository.

## Suggest a feature or get help

Contact your community staff privately. They can discuss the request with you, clarify the desired outcome, and record agreed work in the current backlog. For help with an existing report, give staff its receipt reference privately.

For a security vulnerability, exposed credential, or exploit, contact a maintainer through your community's established private security channel. Do not submit sensitive details through `/report-bug` or a public issue.
